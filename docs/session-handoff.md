次に入るセッションが、まずこれを読めば現況に追いつけることを狙った文書。

## 最初に知っておくこと

### 実行環境によってできることが違う

| | コード編集・テスト・commit | Firebase の読み書き | 公開サイトの確認 |
|---|---|---|---|
| Mac のターミナル | ✅ | ✅ | ✅ |
| Web 版・iPhone | ✅ | ❌ | ❌ |
| Mac へ Remote Control 接続 | ✅ | ✅ | ✅ |

Web 版のセッションは egress ポリシーにより **Firebase・github.io・一般サイトに
到達できない**（CONNECT が 403）。届くのは GitHub API と Web 検索だけ。

Firebase の読み書きや公開ページの確認が要るときは、次のどちらかを取る。

1. **Remote Control でこの Mac に繋ぐ**（制限なし。常駐しているので繋がる）
2. **GitHub Actions を踏み台にする**（手順は `docs/OPERATIONS.md`）

鍵は `mac/.env` にしか無く、リポジトリにも Web 側にも無い。
「Firebase に繋がらない」と感じたら、まず自分がどの環境にいるかを疑うこと。

### このリポジトリは public

Actions のログと artifact も公開される。タスクには手続き・通院・慶弔など
私的な予定が含まれるので、**タスクの中身をログや artifact に出さない**。
件数・構造・フィールド名までに留める（`scripts/inspect-tasks.mjs` が実装例）。

## 常駐している仕組み（launchd・ターミナルとは無関係に動く）

| ラベル | 役割 | 時刻 |
|---|---|---|
| `com.bubblesnow.daily` | タスク候補の生成（収集→学習→選別→Firebase 反映） | 0時 / 14時 |
| `com.bubblesnow.remind` | 期限が近いタスクを Slack に通知 | 8時 / 22時 |
| `com.bubblesnow.remote` | Remote Control（BubblesNow） | 常駐 |
| `com.bubblesnow.remote.daily-hack` | Remote Control（別リポジトリ） | 常駐 |
| `com.bubblesnow.remote.daily-hack-blog` | Remote Control（別リポジトリ） | 常駐 |
| `com.bubblesnow.remote.watchdog` | 上記 Remote Control の見張り | 30秒おき |

いずれも **Mac の電源が入っていれば動く**。ターミナルを閉じても止まらない。

状態の確認:

```
launchctl list | grep bubblesnow        # ロードされているか
tail mac/logs/watchdog.log              # 監視役の記録（正常時は黙る）
tail mac/last-run.md                    # 日次実行の心拍（git にも入る）
```

### plist は install.sh を通すこと

`mac/com.bubblesnow.daily.plist` は `__REPO__` を含むテンプレート。
直接コピーすると起動時に `exit 78 (EX_CONFIG)` で落ち、**静かに2日分の実行が
失われた**（実際に起きた）。`bash mac/install.sh` を使う。

watchdog の plist は絶対パス記述なので直接コピーでよい。

## 今回のセッションで入れた変更（2026-09-23 〜 10-05）

### メールの判定を LLM に置き換えた

**きっかけ**: 「【9月29日まで】ディズニー・クルーズラインの残金お支払い期日」が
タスク候補に出なかった。調べると収集・判定・選別の**3段階すべてで落ちていた**。

1. キーワードの許可語に「支払」「残金」「請求」が一つも無かった。
   同じ差出人の別件は末尾の「について」でたまたま通っており、
   拾えるかどうかが偶然に左右されていた。
2. LLM が取り出した期限を、選別側が捨てて本文から正規表現で取り直していた。
   タイトルは整形済みで「9月29日まで」の文字列がもう無く、空振りしていた。
3. 支払期日のような義務を、お得情報と同じ点数表で競わせていた。
   「50%還元」に負けて25件から漏れる。見逃しの重さが違うものを
   同じ土俵に並べること自体が誤りだった。

**いま**: `scripts/classify-mail.mjs` が本文を読んで todo/deal/skip と期限を返す。
`CLASSIFY=off|validate|live` で切り替え、日次バッチでは live。
判定済みは Message-ID で記録する（`.mail-verdicts-cache.json`・現在797件）。
**記録が効かないと月$2が月$33に跳ねる**ので、ここは費用を決めている部分。
テストで17倍の差を固定してある。

判定が失敗したら従来のキーワード結果に戻る。後退したら心拍に警告が出る
（終了コードは 0 のままなので、これが無いと何週間も気づけない）。

### アプリ側の変更

- **ピンチでバブルの大きさを連続的に変えられる**（従来は4段階に吸着）。
  `task.scale` に倍率を持つが、`category` と同じく単数の `priority` も必ず
  同期させる。下流（Slack リマインド・学習・収集）が見ているため。
- **完了済み・失敗の一覧から詳細を開ける**。確認モード（`mode:"archive"`）で
  完了・失敗・削除を隠し、「↩️ 未完了に戻す」だけを出す。
- **カテゴリを複数付けられる**。`categories`（配列）を足したが、`category`
  は必ず先頭と同じ値を指す。単数を捨てると下流を一斉に書き換えることになる。
- **絞り込みタブが複数選択（AND）**。「すぐ」＋「契約・手続き」で両方に
  該当するものだけ。「🎯 長期を除く」（3ヶ月超と期限なしを外す）も追加。
- **優先度を3段階に**（🟢低 / 🟡中 / 🔴最優先）。「🔴期限迫」は重要度ではなく
  残り時間で別の軸だったため外した。既存データは `PRI_ALIAS` で読み替える。
- **失敗時のアニメーション**。完了と同じ枠で、向きと時間を反転させる
  （落ちる・ひびが入る・色が抜ける）。文字は MISSED。
- **カンバン表示**。期限で3列（3日 / 1週間 / 1ヶ月）＋「それ以降・期限なし」。
  右上の 🗂 で切り替え、選択は localStorage に覚える。既定はバブル。
- **モーダルが閉じられなくなる不具合**。高さ変更グリップの `setPointerCapture`
  が残ると以降のタップを全部吸う。捕捉をやめ、閉じる手段を4つに増やした
  （×クリック / ×タッチ / 背景 / Esc）。

### Remote Control の復帰を速くした

切断はサーバ側の**約12時間周期**（スリープでもローカル回線でもないことを確認済み）。
止められないが、再試行の待ちが指数的に伸びて 2分20秒のうち1分20秒が
「黙って待っているだけ」だった。監視を30秒おき・閾値60秒に詰めた。
一度叩いたら300秒は手を出さない（kickstart は作業ごと消すため）。
正常時は記録しない（30秒おきだと1日2,880行たまる）。

## 踏みやすい落とし穴

- **`Array.map` に関数をそのまま渡さない**。`list.map(toItem)` と書くと
  第2引数に添字が入る。`toItem(v, today)` の `today` が数値になり、
  日付比較が常に false になって**期限切れの除外が丸ごと効かなくなった**。
- **状態の判定は「active 以外を外す」向きで書く**。`done` だけを見ていたため、
  アプリで「失敗」にしたタスクが翌朝も期限切れとして鳴り続けた。
  新しい状態が増えたときに同じ取りこぼしをしないため。
- **`grep -q` と `set -o pipefail` の併用**。一致した時点で終了するので
  上流が SIGPIPE で落ち、pipefail がそれを失敗として伝播する。`awk` を使う。
- **`$VAR` の直後に多バイト文字**。変数名に吸われて `unbound variable` になる。
  `${VAR}` と書く。
- **`.env` に `<` `>` を含む値**。リダイレクトとして解釈されるのでクォートする。
- **絵文字を含む grep は非常に遅い**。Python で読むほうが速い。

## 最上位ルール（`CLAUDE.md` に書いてあるが、守られないことが実証済み）

**未完了の作業が1件でも残った状態でターンを終えるなら、必ず
AskUserQuestion（ダイアログ）を出す。** 地の文で選択肢を並べるのは禁止。
外部イベント待ちで止まるときも同じで、待つ以外の道を選べる形にする。

検知語を避けて書き直すのは、本文に選択肢を並べるより悪い。
差し戻しは「書き方を直せ」ではなく「ダイアログを出せ」という指示。

フックで機械的に強制している（`.claude/hooks/enforce-dialog.py`）。
